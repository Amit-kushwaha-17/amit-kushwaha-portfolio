## 🚀 Running Locally

No complicated setup or build tools required.

### Option 1: Using Node.js (Built-in Server)
```bash
npm start
# Server starts at http://localhost:3000/
```

### Option 2: Using Python
```bash
python -m http.server 3000
```

### Option 3: Using VS Code Live Server
Simply right-click `index.html` and choose **"Open with Live Server"**.

## ☁️ Deploying to Vercel

This repository is pre-configured with `vercel.json` for seamless zero-config deployment on Vercel:

1. Push this repository to GitHub.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import `Amit-kushwaha-17/amit-kushwaha-portfolio`.
4. Framework Preset: **Other** (Root directory: `./`).
5. Click **"Deploy"**.

Your portfolio with the 60 FPS scroll animation will be instantly live worldwide with optimized Edge CDN caching for all 118 image frames.
